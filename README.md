A program that writes the weirdest job title it can think of — one real-sounding job with one hilariously specific twist — to `/output/entry.txt` for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty. A blind judge compares titles two at a time and picks the weirder, funnier one.

The title: **Professional Mourner for Strangers' Goldfish Funerals** — a genuine occupation (professional mourning) hired not for people, but for strangers' goldfish funerals. Pure Python standard library, fully deterministic: every run writes the same 53 characters.

## Run it

```sh
python3 main.py
```
